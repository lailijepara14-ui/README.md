## 🎯 RESEARCH OVERVIEW

### Topic
LinkedIn Organic Content Strategy for B2B SaaS

### Goal
Collect and analyze content from 10 top B2B SaaS LinkedIn experts to build a foundation for a practical marketing playbook.

### Methodology
1. Identify 10 experts who actively practice LinkedIn content strategy
2. Collect 3 recent LinkedIn posts from each expert
3. Extract YouTube video transcripts using Supadata API
4. Organize all data in GitHub repository
5. Analyze patterns and key insights

### Tools Used
- **Supadata API** - Extract YouTube transcripts
- **GitHub** - Repository and version control
- **LinkedIn** - Manual content collection
